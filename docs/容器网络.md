# 容器网络

执行下面的命令，查看所有的网络。

```
docker network ls
```

执行下面的命令，创建指定的网络。

```
docker network create demo
```

执行下面的命令，查看指定网络的全部信息。

```
docker network inspect demo
```

执行下面的命令，删除指定的网络。

```
docker network rm demo
```

执行下面的命令，将容器接入网络。

```
docker network connect demo CONTAINER_ID
```

执行下面的命令，将容器断开网络。

```
docker network disconnect demo CONTAINER_ID
```
