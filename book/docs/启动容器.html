启动容器

执行下面的命令，基于镜像创建容器并启动。

docker run redis

执行下面的命令，使用后台守护进程运行容器。

docker run -d redis

执行下面的命令，创建容器并指定名称。

docker run --name redis redis

执行下面的命令，配置容器端口映射。

docker run -p 6379:6379 redis

执行下面的命令，将宿主机指定目录映射到容器内部。注意，宿主机中目录内容将覆盖容器目录内容。

docker run -d --name redis -p 6379:6379 -v /docker/redis:/data redis

执行下面的命令，将数据卷映射到容器内部。注意，若数据卷为空，则将容器目录内容复制到数据卷，若数据卷非空，则直接读取当前数据卷内容。

docker run -d --name redis -p 6379:6379 -v redis:/data redis

执行下面的命令，启动容器并指定网络。

docker run -d --name redis -p 6379:6379 --network demo redis

执行下面的命令，启动已经存在但处于停止状态的容器。

docker start CONTAINER_ID

执行下面的命令，停止正在运行的容器。

docker stop CONTAINER_ID

执行下面的命令，重新启动容器。

docker restart CONTAINER_ID
