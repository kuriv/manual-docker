下载镜像

执行下面的命令，下载指定的镜像。

docker pull redis

执行下面的命令，下载指定的镜像的最新推送版本。

docker pull redis:latest

执行下面的命令，下载指定版本的镜像。

docker pulll redis:8.10.1
